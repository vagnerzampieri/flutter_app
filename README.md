# Branches

- main - The main branch
- my-app - How the AppBar works
- navigation - How to navigate between screens
- bottom-navigation - How to use the bottom navigation bar
- counter-app - A simple counter app
- user-input - How to get user input

### Running

```bash
flutter run
```

Or you can go to `lib/main.dart` and run the main function. Or you can run and debug using the vscode debugger.
